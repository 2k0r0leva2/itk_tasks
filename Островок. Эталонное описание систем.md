

| Название системы | CMS (Content Management System) |
| :---- | :---- |
| Категория | SoE (System of Engagement) |
| Роль в бизнесе | Воронка, повышает конверсию бронирований, увеличивает количество клиентов |
| Входящие потоки | Просмотр доступных бронирований от Пользователя |
| Исходящие потоки | Логин, пароль в Auth Service Бронирование в CRS Данные клиента в CRM |

| Название системы | PMS (Property Management System) |
| :---- | :---- |
| Категория | SoE (System of Engagement) |
| Роль в бизнесе | Повышает количество партнеров |
| Входящие потоки | Управление объектами от Пользователя |
| Исходящие потоки | Логин, пароль в Auth Service Данные объектов в CRS Данные управляющего в CRM |

| Название системы | CRM (Customer Relationship System) |
| :---- | :---- |
| Категория | SoE (System of Engagement) |
| Роль в бизнесе | Обеспечивает “теплую” базу клиентов и владельцев объектов, повышает количество повторных продаж |
| Входящие потоки | Просмотр доступных бронирований от Пользователя |
| Исходящие потоки | Логин, пароль в Auth Service Бронирование в CRS Данные клиента в CRM |

| Название системы | CDN (Content Delivery Network) |
| :---- | :---- |
| Категория | SoE (System of Engagement) |
| Роль в бизнесе | Обеспечивает доставку контента, повышает вероятность бронирования |
| Входящие потоки | Статические ресурсы от CMS |
| Исходящие потоки | Картинки, CSS/JS к Пользователю |

| Название системы | Платежный шлюз |
| :---- | :---- |
| Категория | SoR (System of Record) |
| Роль в бизнесе | Обеспечивает финансовый поток, гарантирует безопасность финансовых операций |
| Входящие потоки | Платежное поручение от CRS |
| Исходящие потоки | Статус оплаты к CRS |

| Название системы | CRS (Central Reservation System) |
| :---- | :---- |
| Категория | SoR (System of Record) |
| Роль в бизнесе | Источник истины об объектах и их бронированиях, обрабатывает процесс бронирования, обеспечивает защиту от овербукинга |
| Входящие потоки | Бронирование от CMS-витрины Данные объектов от PMS Статус оплаты от Платежного шлюза |
| Исходящие потоки | События бронирования в Message Broker Платежное поручение в Платежный шлюз |
